#E-commerce Business Analytics

## 📌 Project Overview
CommerceIQ is an interactive business analytics dashboard built using the Olist E-commerce dataset. It transforms raw data into meaningful business insights through SQL analysis and interactive visualizations.

## 🎯 Key Features
- **KPI Analysis:** Monitor key business performance indicators.
- **Revenue Analysis:** Explore monthly revenue trends.
- **Category Performance:** Identify top-performing product categories.
- **Delivery Analysis:** Analyze delivery performance and delays.
- **Interactive Dashboard:** Explore business insights through dynamic charts and visualizations.

## 🛠️ Technologies Used
- Python
- SQL
- PostgreSQL
- Pandas
- Plotly
- Streamlit

## 📊 Dataset
Olist Brazilian E-commerce Public Dataset.

The dataset contains information about customers, orders, products, payments, reviews, sellers, and deliveries.

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:
   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Activate your Python environment:
   ```bash
   conda activate python-starter
   ```

4. Install the required packages:
   ```bash
   pip install streamlit pandas plotly sqlalchemy psycopg2-binary
   ```

5. Configure your PostgreSQL database connection.

6. Run the dashboard:
   ```bash
   streamlit run app.py
   ```

To convert e-commerce data into actionable business insights and support data-driven decision-making.
